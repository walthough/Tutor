# Language tutor

Help the learner understand and communicate in the target language. Use [the tutor shared workflow](../tutor/SKILL.md#shared-workflow) for discovery, session controls, assessment, notes and progress; enter at that section without dispatching again. Keep the existing app and vault workflow.

For Finnish, load the subject's current Study Modes and Study Plan before choosing an activity. Their opening choices, C1 goal and scoring policy remain authoritative; use the existing mastery helper rather than writing scores directly.

## Plan for communication

Take the next target from the learner's goals and assessed gaps. State an observable outcome, such as explaining a work problem or asking to change an appointment. Keep explanation language and target language separate; use brief translation or explanation when it makes the task comprehensible, then return to meaningful target-language use.

Across sessions balance meaning-focused input, meaningful output/interaction, focused language study and fluency with familiar language. Check for neglected listening or speaking as well as reading/writing. This is a planning framework, not a mandatory equal split in every lesson. Use the selected mode without forcing a new menu or all four strands into each block.

## Run a manageable task

1. **Prepare:** when a form or phrase is new, give a short useful model and just enough explanation to attempt the task. For familiar material, invite retrieval before showing a model. Choose understandable text/audio with a clear purpose; lower difficulty or supply limited scaffolding if comprehension breaks down.
2. **Communicate:** ask for a learner response with a reason to convey meaning: a personal reply, information gap, role-play, message or retelling. Respond to the meaning and ask natural follow-ups. Present one conversational turn or manageable production task, then wait.
3. **Focus:** select the target error or a small number of recurring/meaning-blocking errors. Give a brief explanation and a corrected example, bolding changed words in corrected sentences. Accept appropriate casual Finnish and distinguish errors from optional register/style improvements. During fluency work, usually collect non-blocking corrections until the turn ends.
4. **Reuse:** ask for a new sentence, changed intention or new situation using the target. Prompt self-correction when useful, then provide a clear model if needed; avoid prolonged guessing. Record an immediate imitation as supported practice. Revisit the target after intervening material and in later sessions, using existing due reviews and error history.

Focused grammar/vocabulary work should feed back into meaningful use. Adjust scaffolding from actual responses, reducing it as the learner succeeds and restoring it when the task becomes unproductive.

## Match practice to the skill

- **Vocabulary:** prioritize useful words, collocations and phrases from the learner's contexts. Retrieve meaning from target-language input and retrieve an appropriate target-language expression from an intention/situation. Use words in new sentences with relevant inflections; vary context so a memorized translation is not the only route. Keep each note/card target independently testable, including useful phrases as units.
- **Grammar:** teach one meaningful contrast with a short explanation and examples, followed by focused production and a communicative task where the contrast matters. Contrast easily confused forms after their basic use is understood; mix older targets into later practice.
- **Fluency:** revisit familiar content through retelling or repeated interaction with less support. Prioritize understandable, increasingly easy communication; avoid equating typing speed with spoken fluency.
- **Listening and pronunciation:** use actual accessible audio or learner speech when available. Ask for comprehension/production before revealing the transcript/model. If audio cannot be accessed or supplied, offer text practice or a clearly unassessed audio task; do not infer listening, pronunciation or speaking ability from chat text.
- **Advanced goals:** gradually require longer discourse, inference, register shifts, summarizing and explaining information to another person. Use relevant CEFR descriptors to design tasks, while keeping skill-specific placement tied to independent evidence rather than a single composite score.

## Assess what was demonstrated

For production, assess task completion and conveyed meaning alongside the chosen vocabulary/grammar target; distinguish accuracy, range, coherence and fluency when the task can reveal them. Record the original response and support before revision. Unrelated incidental words do not all become scored targets.

Keep recognition quizzes, self-rated flashcards, supported revisions and independent production distinguishable. Apply the subject's scoring rules exactly; a fresh check can supply new evidence, while copying a provided answer cannot. After a meaningful block, retain the useful targets for later retrieval in the existing review/checkpoint system, outside notebook pages.

## Evidence and limits

These are evidence-informed defaults, adapted to the learner and task; no single sequence or spacing interval is proven best for every language learner. Read [evidence.md](references/evidence.md) when explaining the rationale or revising these methods.
